# Excel Sales Performance Dashboard

## Project Overview
An interactive Sales Dashboard built using Microsoft Excel to analyze sales performance across products, locations, months, and salespeople.

## Dashboard Features
- Total sales KPIs
- Monthly sales trend analysis
- Product-wise sales comparison
- Location-wise sales performance
- Top and bottom-selling products
- Salesperson performance analysis
- Interactive filters and visualizations

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Data Analysis and Visualization

## Project Files
- Excel workbook containing the dashboard
- Dashboard screenshots
- 30-second dashboard demonstration video

## Objective
To practice data analysis and present sales data through an interactive, visually appealing dashboard.
